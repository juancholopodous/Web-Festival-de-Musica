# 🎫 Festival Web — Landing Page de Evento (Proyecto Front-End)

Landing page desarrollada para un evento musical ficticio, diseñada para ofrecer una experiencia visual atractiva, fluida y optimizada en rendimiento.

El proyecto simula el sitio oficial de un festival, incluyendo video de portada, información del evento, cronograma por fechas, galería interactiva y una sección de compra ficticia de boletos.

---

## 🚀 Características principales

- 🎬 Video de portada optimizado y responsive
- 🧭 Navegación fija con resaltado dinámico según la sección
- 🖼️ Galería interactiva con ampliación modal
- 🔒 Bloqueo de scroll al visualizar imágenes ampliadas
- 🎟️ Sistema de boletos con animaciones sutiles
- 📅 Sección de fechas y line-up organizado por día y hora
- 🧑‍🤝‍🧑 Sección “Nosotros”
- ✨ Animaciones de desplazamiento (scroll)
- 📱 Diseño completamente responsive

---

## ⚙️ Optimización y rendimiento

Se aplicaron múltiples mejoras para performance y carga:

- Lazy loading de imágenes
- Compresión de hojas de estilo
- Minificación de scripts mediante Gulp + Terser
- Uso de sourcemaps para desarrollo
- Optimización de recursos multimedia
- Reducción de peso en assets visuales

---

## 🛠️ Tecnologías utilizadas

- HTML5
- SASS / SCSS (arquitectura modular con mixins y variables)
- JavaScript ES6+
- Gulp (automatización de tareas)
- Terser (minificación)
- Lazy Loading nativo
- CSS Grid y Flexbox

---

## 🧩 Arquitectura de estilos

El proyecto utiliza SASS para una mejor organización y escalabilidad:

- Variables reutilizables
- Mixins para media queries y layouts
- Sistema de contenedores y grids
- Normalización de listas y componentes
- Archivos parciales estructurados por secciones

---

## 🖼️ Funcionalidad de galería

- Carga dinámica de imágenes mediante JavaScript
- Modal con animación de entrada y salida
- Cierre controlado con botón dedicado
- Bloqueo de scroll del fondo durante la visualización
- Transiciones suaves configuradas en SCSS

---

## 🎟️ Sistema de boletos

Se implementa una simulación de compra con dos tipos de tickets:

- Animaciones en el cuerpo del boleto
- Micro-interacciones en botones
- Diseño visual distintivo por tipo de entrada

---

## 📦 Automatización con Gulp

El flujo de trabajo incluye:

- Compilación de SASS a CSS
- Minificación de archivos
- Generación de sourcemaps
- Optimización para producción
- Exportación mediante tareas en serie

---

## 📌 Objetivo del proyecto

Practicar y demostrar habilidades de desarrollo front-end moderno, optimización de rendimiento y organización de código escalable para proyectos reales.
